# 🛠️ Recommended Organization Standards

To keep the repository maintainable as it grows:

### 1. Use meaningful filenames

Prefer:

```text
Binary_Search_Notes.pdf
OOP_Inheritance_Examples.pdf
Database_Assignment_01.pdf
```

instead of:

```text
file1.pdf
new.pdf
final2.pdf
```

### 2. Group related resources

Keep files belonging to the same course, topic, or project together.

### 3. Avoid unnecessary duplicates

Before uploading a new resource, check whether an equivalent version already exists.

### 4. Keep important resources documented

For larger collections, add a small README inside the relevant directory explaining its contents.
